# DevSweep marketing assets

These files are reusable outside the Xcode project:

- `devsweep-dashboard.jpg` — current product screenshot, 1024 × 407
- `devsweep-app-icon.png` — full-resolution app icon artwork, 1024 × 1024

The repository README references these files with relative paths. Keep their filenames stable unless the README is updated at the same time.

For a portfolio website, copy assets from this directory rather than from `Assets.xcassets`, which contains platform-specific resized icon files.
